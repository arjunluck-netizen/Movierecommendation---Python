# Dataset / Attribution Note

The project uses the TMDB 5000 Movie Dataset available through Kaggle.

Please review the current Kaggle dataset page and its stated terms before redistributing raw data:

https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata

The Kaggle page states that the dataset was generated from The Movie Database (TMDb) API and is not endorsed or certified by TMDb.

This repository intentionally does not include the raw CSV files.
